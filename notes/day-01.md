What is Resource Group?-- A resource group is a container (folder) that holds related Azure resources so you can manage them together, delete all resources by just deleting group, giving permission to someone to access using IAM, check how much project costs by looking at its group.
Every resource belongs to exactly one group.  A group lives inside a subscription.  The hierarchy is: Subscription → Resource group → Resources.  A group has a region, but the resources inside it can be in other regions
